# ADR-0009: MinIO для объектного хранения файлов

**Date**: 2026-05-24
**Status**: proposed
**Deciders**: автор проекта, проектная команда

## Context

Текущий объем системы не требует долговременного хранения исходных импортов и сформированных экспортов. Импорт может обрабатываться во временном каталоге, а экспорт - формироваться по запросу и сразу передаваться клиенту. Объектное хранилище может понадобиться позднее, если появятся долговременные артефакты, большие асинхронные файлы или требование повторного скачивания.

## Decision

Рассматривать MinIO как вариант будущего S3-совместимого объектного хранилища. До перевода ADR в `accepted` система не хранит бинарные объекты долговременно: импорт принимает файл через backend, удаляет временную копию после обработки и сохраняет только нормализованный staging JSON; экспорт формируется синхронно и передается потоковым HTTP-ответом. При принятии MinIO доступ реализуется через порт хранения объектов с возможностью использовать существующее хранилище ВУЗа.

## Alternatives Considered

### Файловая система серверов

- **Pros**: минимальная начальная конфигурация.
- **Cons**: усложняет репликацию, масштабирование, резервное копирование и независимое развертывание.
- **Why not**: локальный диск экземпляра backend не является надежным постоянным хранилищем.

### Хранение бинарных данных в PostgreSQL

- **Pros**: единая транзакция данных и метаданных.
- **Cons**: рост базы, тяжелые резервные копии и неэффективная раздача больших объектов.
- **Why not**: PostgreSQL хранит только метаданные и ссылки на объекты.

## Consequences

### Positive

- Текущая поставка не содержит дополнительного stateful-компонента.
- При появлении требования сохраняется понятный путь к S3-совместимому хранилищу.

### Negative

- Исходный импорт и сформированный экспорт нельзя скачать повторно без повторной операции.
- Сбой во время обработки требует повторной загрузки файла.

### Risks

- Временные файлы могут остаться после аварийного завершения; используются изолированный каталог с лимитом, очистка при старте и гарантированное удаление после обработки.
